# 포트폴리오-레주메 디자인 개편 계획

## 컨텍스트
기존의 단순한 다크 모드 포트폴리오 사이트를 현대적이고 세련된, 하이엔드 디지털 경험으로 전환하는 것이 목표입니다. 현재 디자인은 기본적인 다크 테마이며, 이번 개편을 통해 제공된 참고 이미지와 같이 깊이감, 정교한 타이포그래피, 폴리싱된 시각적 요소들을 도입할 예정입니다.

## 구현 접근 방식

### 1. 시각적 정체성 및 글로벌 스타일
- **딥 다크 테마**: 평면적인 `#09090b` 배경에서 더 깊은 `#050505` 톤으로 전환합니다.
- **세련된 포인트 컬러**: 기존의 밝은 블루(`#3b82f6`)를 전문적이고 현대적인 틸/시안(Teal/Cyan, 예: `#2dd4bf`) 계열로 교체합니다.
- **깊이감 및 조명**: 
    - 배경에 방사형 그라데이션 "글로우" (예: 틸, 퍼플)를 추가하는 커스텀 CSS 유틸리티 클래스를 도입하여 평면성을 제거합니다.
    - 사이트 전반에 글래스모피즘 적용: `backdrop-blur-xl`과 반투명 테두리(`border-white/10`)를 결합합니다.
- **타이포그래피**:
    - 강렬한 임팩트를 위해 헤드라인의 무게감과 크기를 키웁니다.
    - 큰 제목에는 `tracking-tighter`(좁은 자간)를, 본문에는 `leading-relaxed`(여유로운 행간)를 적용합니다.

### 2. 히어로 섹션 전면 개편
- **레이아웃**: 중앙 정렬 방식에서 `grid md:grid-cols-2` 기반의 스플릿 레이아웃으로 변경합니다.
- **콘텐츠 (좌측)**:
    - 소프트 글로우가 적용된 "Available for Freelance" 알림 배지를 추가합니다.
    - 메인 헤드라인을 "Crafting Digital Experiences"와 같은 고임팩트 문구로 업데이트합니다.
    - CTA 버튼 재설계: 고대비의 채워진 틸 컬러 버튼("Hire Me")과 글래스모피즘이 적용된 고스트 버튼("Download CV")으로 구성합니다.
- **비주얼 (우측)**:
    - 고품질 3D 캐릭터/에셋을 도입합니다.
    - 에셋을 플로팅 애니메이션과 은은한 배경 글로우가 포함된 컨테이너로 감쌉니다.

### 3. 컴포넌트 디테일 개선
- **네비게이션**: `backdrop-blur` 강도를 높이고 테두리를 `border-white/10`으로 부드럽게 수정합니다.
- **프로젝트 카드**: 
    - 테두리를 `border-white/5`로 변경합니다.
    - 호버 시 테두리 불투명도를 `border-accent/50`으로 높이고 은은한 외부 광채(Glow)가 나타나는 효과를 구현합니다.
    - 이미지에 일관된 비율을 적용하고 호버 시 살짝 확대되는 트랜지션을 추가합니다.
- **스킬 배지**: 평면적인 배경에서 글래스 스타일 배지(`bg-white/5`, `backdrop-blur-sm`, `border-white/10`)로 전환합니다.
- **간격**: 섹션 간 세로 패딩을 늘려(예: `py-24` $\rightarrow$ `py-32`) 더 여유롭고 프리미엄한 느낌을 줍니다.

### 4. 애니메이션 및 인터랙션
- **유기적인 트랜지션**: `.reveal` 애니메이션의 타이밍 함수를 선형에서 `cubic-bezier(0.22, 1, 0.36, 1)`로 변경하여 더 빠르면서도 부드러운 느낌을 줍니다.
- **플로팅 효과**: 히어로 에셋이 부드럽게 위아래로 움직이는 `@keyframes` 애니메이션을 추가합니다.
- **글로우 펄스**: 배경의 방사형 그라데이션이 아주 천천히 맥동하는 애니메이션을 구현하여 생동감을 부여합니다.

## 검증 계획
1. **시각적 감사**: 렌더링된 페이지를 참고 이미지와 비교하여 다음 사항을 확인합니다:
    - 컬러 팔레트 및 배경 깊이감의 적절성.
    - 타이포그래피의 임팩트와 계층 구조.
    - 글래스모피즘 및 간격 구현 상태.
2. **반응형 확인**: 스플릿 레이아웃의 히어로 섹션이 모바일 기기에서 자연스럽게 전환되는지 확인합니다.
3. **애니메이션 테스트**: 스크롤 리빌 및 플로팅 애니메이션이 끊김 없이 부드럽게 작동하는지 확인합니다.
4. **인터랙션 확인**: 카드와 버튼의 호버 상태가 정교하고 촉각적인 반응을 주는지 확인합니다.
