모델 비교

모델 특징 언제 쓰면 좋은지
Opus 가장 똑똑, 토큰 4~5배 소모 복잡한 설계, 어려운 버그
Sonnet 균형 잡힘, 대부분 작업 충분 일반 코딩, 파일 수정, 기능 구현
Haiku 가장 빠르고 저렴 간단한 질문, 파일 검색

출처: Claude Code 공식 문서

모델 비유

Opus = 시니어 개발자
Sonnet = 중급 개발자
Haiku = 주니어 개발자

시니어한테 복사 붙여넣기 시키는 건 낭비
