설계는 오푸스로 하고 코딩은 소넷으로 하고 싶은데, 계획 승인 누르면 바로 실행으로 넘어가서 모델 바꾸는 걸 자꾸 놓쳐요

이미 있는 기능

계획 짤 때는 Opus, 코딩할 때는 Sonnet

이 기능, 이미 있습니다 — opusplan

opusplan 작동 원리

계획 모드 → Opus

계획 승인 후 → Sonnet 자동 전환

시연 — 명령어

(출처: Claude Code 공식 문서)


/model opusplan

매번 입력하기 귀찮으면 settings.json에 설정

settings.json 설정


{
  "model": "opusplan"
}
