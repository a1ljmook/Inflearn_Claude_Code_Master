Section 2

Agent Teams란?

여러 개의 독립된 Claude Code 세션이
하나의 팀으로 묶여서 같이 움직입니다

✓ 독립된 컨텍스트
✓ 메시지 주고받기
✓ 공유 작업 목록
✓ 진짜 팀으로 협업

혼자 일하는 도우미가 아니라, 진짜 팀이에요.
각 팀원이 자기만의 별도 컨텍스트를 가지고 있는데,
서로 메시지를 주고받을 수 있고, 공유 작업 목록을 보면서 같이 일합니다.
